# Design Taste: Grid & Systemization

> Layer tags: `L1` foundation (always), `L2` tonal preset (only for that tone), `L3` brand-negotiable. `Rnnn` = the comparison round that produced the rule (see ../evidence.md). Non-negotiables in SKILL.md survive any brand override.

- **Reflow by relationships, not fixed sizes.** When a layout moves to another format, adjust type size and column widths to keep the comfortable measure and the hierarchy intact. Never scale one recipe from the width. `L1` · R003, R070
- **Restructure for the aspect ratio.** Portrait formats stack image over text. Landscape formats split side by side, with the image taking one half, which reads first, and the text the other. The reading order survives: image first, then the text chain. Size type and margins from the shorter side, so margins stay proportionally consistent across formats. `L1` · R070
- **Every format must be beautiful and legible, so re-set the copy per format.** When a format gets cramped, restore the breathing room by changing how the copy is set, not by squeezing the gaps. Re-break the headline into fewer lines, or set the subhead on one line. Line breaks are per-format decisions. Use judgment: an output that technically fits but feels cramped has failed. `L1` · R070
- **Strict grid by default, with deliberate deviation only.** Modular alignment and consistent margins are the default. Departures must be bold and intentional (see Composition). `L1` · R001, R013, R057, R069
- **Lean toward strict grid adherence.** Equal margins and shared column edges are what make a composition feel resolved. Intuitive or by-eye placement is a liability, not a style. `L1` · R001 (partial — still to test how much rule-breaking a strong grid can absorb)
