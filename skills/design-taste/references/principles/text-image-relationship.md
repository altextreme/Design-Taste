# Design Taste: Text / Image Relationship

> Layer tags: `L1` foundation (always), `L2` tonal preset (only for that tone), `L3` brand-negotiable. `Rnnn` = the comparison round that produced the rule (see ../evidence.md). Non-negotiables in SKILL.md survive any brand override.

- **Small labels sit on the image by default rather than claiming their own band.** When an image bleeds to the top, overlay a minor label such as the kicker in a reversed color instead of pushing the image down or giving the label its own strip. Spending a whole band of the page on a tiny label wastes immersion. `L1` · R008, R009
- **Overlay only where contrast can be guaranteed. Otherwise move the text into the text zone.** If a label is essential to understanding the piece and the image can't guarantee accessible contrast behind it, relocate it to the solid text area. Legibility outranks immersion. `L1` · R009
- **Text on an image is limited to two cases: minor labels and large, clearly contrasting headlines.** Essential practical information, such as dates, places and calls to action, never sits on the image. It goes in the solid text zone where its legibility is guaranteed. A minor label can overlay because nothing breaks if it's missed. `L1` · R009, R017
- **Type over a busy photograph: gradient scrim first, solid panel as the backup.** When type must sit on imagery, darken the image behind it with a gradient that fades into the photo. The type stays clean and the image keeps its full bleed. If a scrim can't secure contrast, use a solid panel in a color sampled from the photo. A shadow on the type alone is never enough; it makes busy-background text extremely hard to read. A barely perceptible shadow combined with a gradient scrim is acceptable as a finishing touch, to nudge legibility while keeping the type looking clean. The scrim does the work, and the shadow only refines it. `L1` · R071
- **Captions sit on the image, quietly.** A caption identifying an image belongs on the image itself, as close as possible to what it describes. It's set small and slightly dimmed so it never distracts from the picture. Place it in the least competing corner, usually the lower right, where the eye finishes reading the image. The exact placement varies with each image. Dimming stops at the accessible contrast floor, as with the other secondary text (R038). `L1` · R072
- **In long-form layouts, set images beside the text, not in separate stacked blocks.** Placing an inset image alongside the copy, with the text wrapping around it, gives the body a comfortable measure and makes the page feel considered. An image stacked above full-width text is oversimplified, and the lines run long. A rectangular wrap is always acceptable. A shaped wrap, where the text follows a contour, is preferred when the shape comes from the concept, such as an arched window for a show about light and windows. `L1` (wrap) · `L2` (shaped, concept-driven) · R073
- **Overlay and image size are separate decisions.** Freeing space by overlaying a label doesn't mean the image should grow into it. Set the image size by proportion first, then decide where labels go. `L1` · R009
